# 电商用户销售与行为分析（Pandas 版）

## 项目背景

用 Pandas 重写「电商用户销售与行为分析」SQL 项目，对比 SQL 和 Pandas 两种工具的实现差异。

## 数据说明

- users.csv：用户表，20 条（user_id, gender, age, register_date）
- products.csv：商品表，15 条（product_id, product_name, category, price）
- orders.csv：订单表，60 条（order_id, user_id, product_id, quantity, order_date, order_status）

## 分析问题与结论

### 1. 商品销量排名
数据线D（19件）、鼠标J（10件）、耳机B（9件）排前三。

### 2. 商品销售额排名
笔记本H（35996元）、手机A（23994元）、笔记本G（17997元）排前三。

### 3. 月度销售额
- 2024-07：47825 元
- 2024-08：43919 元
- 2024-09：36057 元

### 4. 用户消费排名
Top1：user_id 5（男，35岁），消费 18375 元。

### 5. 复购率（用户维度）
复购用户 18 / 总用户 19 = 94.74%

### 6. 复购率（订单维度）
复购订单 35 / 总订单 54 = 64.81%

### 7. 用户分层（qcut 4 档）
按消费额分 Q1~Q4，Q4 为消费最高档。

### 8. 品类分析
电脑（53993元）、手机（48083元）贡献主要销售额，数码配件薄利多销。

### 9. 年龄分层消费
25-34 岁人数最多，35-44 岁人均消费最高。

### 10. 月度复购率
- 2024-07：58.33%
- 2024-08：5.88%
- 2024-09：0.00%

### 11. 消费间隔分析
用户平均每 18.1 天复购一次，最短 11 天，最长 27 天。
